Breath Flow v1.2.0｜搬貨工作呼吸節律 · 手機直式適配版

使用方式：
1. 解壓縮，開啟 BreathFlowWeb 資料夾。
2. 雙擊 index.html，即可離線使用；也可上傳至 GitHub Pages。
3. 手機直式畫面直接看到：模式切換、動態呼吸圓圈、倒數、進度、開始/暫停/結束。
4. 點擊右上角「設定」，開啟可獨立捲動的設定面板；點「關閉」返回播放器。

v1.2.0 變更：
- 使用 100dvh 與 CSS clamp/min 自適應手機可用寬、高，不再固定 310px/365px 的大圓圈區。
- 依短螢幕高度自動收緊卡片間距，讓主要操作區在手機直式的一屏內。
- 原本側欄改成手機右側設定抽屜，桌機仍維持左右雙欄。
- 響應式測試尺寸：320×568、360×640、375×667、390×844、412×915、430×932。
- 保留 v1.1.0 的開工前/休息室呼吸與原版非工作時間安全確認。
- 極小高度 (<496 CSS px) 或系統字體大幅放大時允許垂直捲動，以避免裁切和降低可讀性。

安全：本工具不能測量或保證內啡肽分泌，工作前及工作間請只使用溫和呼吸模式。
